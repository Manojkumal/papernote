
## DeCoAgent: Smart Contract Based Decentralized Autonomous LLM Collaboration Framework

## note
## The Problem: Why DeCoAgent was Created

 Most current AI agent systems are fixed and closed. This means:

 Agents are designed to work only with specific partners they already know
They assume everyone is honest and trustworthy

But in real life:

* Different agents may not know each other
* They may not trust each other
* They could be in different places or organizations

So, current systems don’t work well in real-world situations like supply chains or global collaboration.

## The Solution: A Marketplace for AI Agents

DeCoAgent works like an open marketplace for AI agents.

Agents can join, show their skills, and find tasks
They can hire other agents to complete work
Everything is managed by blockchain smart contracts

This ensures:

* No need to trust others beforehand
* All actions are recorded and transparent
* The system is fair and automatic
* How the System Works (The Six Modules)

These six parts help the agent think, act, and communicate:

1. Planner
Takes a human request (in simple language)
Breaks it into a step-by-step plan (workflow)
2. Verificator
Checks the plan for mistakes or unsafe actions
Helps avoid AI “hallucinations” (wrong or made-up info)
3. Communication
Lets agents talk to each other
Helps find the best agent for a specific task
4. Controller
Converts the plan into blockchain actions
Allows the agent to interact with smart contracts automatically
5. Observation
Monitors what’s happening on the blockchain
Checks task progress and agent activity
6. Memory
Stores useful information (like agent skills)
Reduces the need to repeatedly check the blockchain
The Role of Smart Contracts

## Smart contracts handle all interactions. Key functions include:

* Register: Agents sign up and list their skills
* Post Task: Users or agents post jobs with payment
* Request/Deploy Task: Agents take and complete tasks
* Rating: Employers rate workers to build reputation

## Key Findings and Performance
* Prompting: Giving the AI a few examples (2 or more) helps it follow instructions better
* Testing: The system was tested using Ethereum and GPT-4
* Result: Agents could:
    * Understand human instructions
    * Turn them into blockchain actions
    * Work together automatically without human help
## Why This Matters

DeCoAgent makes it possible for AI agents to work together in open, real-world environments.
